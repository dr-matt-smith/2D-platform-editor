# LevelManifestEntry

`apps/editor/src/LibraryEntries.ts` · interface

One bundled level in `content/data/levels/manifest.json` (generated by
`deno task gen:levels`).

## Relationships
- read by [LevelLibrary](LevelLibrary.md)`.init`; becomes a [LevelListItem](LevelListItem.md)

## Members
| Member | Kind | Description |
|---|---|---|
| `id` | property | The level's id (file name without `.txt`) |
| `name` | property | Display name |
| `file` | property | File under `data/levels/` |
| `group` | optional property | Grouping label |

## Example
```json
{ "id": "tutorial", "name": "tutorial", "file": "tutorial.txt" }
```

## Design notes
The shape of generated JSON, as an interface.
