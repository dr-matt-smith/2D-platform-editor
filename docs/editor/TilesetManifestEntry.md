# TilesetManifestEntry

`apps/editor/src/LibraryEntries.ts` · interface

One tileset in `content/data/tilesets/manifest.json` (generated by
`deno task gen:tilesets`).

## Relationships
- returned by [LevelLibrary](LevelLibrary.md)`.tilesets()`; listed by [TilesetMenu](TilesetMenu.md) and [LevelDialog](LevelDialog.md)

## Members
| Member | Kind | Description |
|---|---|---|
| `id` | property | Folder name, as written in `# tileset:` |
| `name` | property | Display name |

## Example
```json
{ "id": "Dirt_Platformer_Tiles", "name": "Dirt Platformer Tiles" }
```

## Design notes
The shape of generated JSON, as an interface.
