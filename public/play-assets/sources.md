# Playtest asset sources

These files power the **playtest** mode of the 2D Platform Editor. They
were **vendored from**
[`dr-matt-smith/simple-platformer-1`](https://github.com/dr-matt-smith/simple-platformer-1)
at commit `4c3b936`, where they were generated as original artwork by
`tools/gen-sprites.mjs`. The upstream project is **© 2026 Matt Smith
(dr-matt-smith)** and licensed **CC BY 4.0** — full text in `./LICENSE`
in this directory and at
<https://creativecommons.org/licenses/by/4.0/legalcode>.

## Files

- **`player.png`** — player sprite (32×32 RGBA)
    - origin: generated by upstream `tools/gen-sprites.mjs` (original
      artwork), then **recoloured by this repository** — green body
      `rgb(110,205,90)` with a forest-green rim `rgb(50,120,40)`, so it
      reads distinctly from `coin.png` and the accent-orange `Goal`.
    - regenerate: `node scripts/gen-player-sprite.mjs` (geometry follows
      upstream; only the palette differs).
    - licence: CC BY 4.0. Adapted Material per Section 2(a)(1)(B).
- **`coin.png`** — coin pickup sprite (32×32 RGBA), **unmodified**
  upstream artwork.
- **`spike.png`** — spike hazard sprite (32×32 RGBA), **unmodified**
  upstream artwork.
- **coin pickup sound** — no file. Synthesised at runtime with the Web
  Audio API in `src/play/core/assets.js` (`AssetLoader.synth`/`play`),
  vendored from upstream `src/js/core/assets.js`; the recipe is original
  to the upstream project, **unmodified** here.
