# Asset sources

All media in this game is **original to this repository** and released under the
project's Creative Commons licence (see `/LICENSE`). Nothing here is taken from a
third party, so it can be reused under those terms with attribution.

- **player.png** — player sprite (32×32 RGBA)
    - origin: generated by `tools/gen-sprites.mjs` in this repo (original artwork).
    - licence: project licence (Creative Commons — see `/LICENSE`).

- **coin.png** — coin pickup sprite (32×32 RGBA)
    - origin: generated by `tools/gen-sprites.mjs` in this repo (original artwork).
    - licence: project licence (Creative Commons — see `/LICENSE`).

- **spike.png** — spike hazard sprite (32×32 RGBA)
    - origin: generated by `tools/gen-sprites.mjs` in this repo (original artwork).
    - licence: project licence (Creative Commons — see `/LICENSE`).

- **coin pickup sound** — no file
    - origin: synthesised at runtime with the Web Audio API in
      `src/js/core/assets.js` (`AssetLoader.synth`). There is no audio file to
      attribute; the recipe is original to this repo.
    - licence: project licence (Creative Commons — see `/LICENSE`).

## History

Earlier versions of this project bundled sprites and a coin sound taken from the
kaplay demo site. Those were removed because kaplay's licence carries extra
restrictions incompatible with releasing this as a Creative Commons project; they
have been fully replaced by the original assets above. To regenerate the sprites:

```bash
node tools/gen-sprites.mjs
```
